# MadridAPasos
Madrid ClimaRutas es una aplicación web que calcula rutas peatonales por Madrid adaptadas al clima en tiempo real, priorizando sombra, fuentes, refugios y lugares de interés según la estación del año y las condiciones meteorológicas.


Para iniciar la aplicación. Descargar la Carpeta >Click derecho > Iniciar en terminal > Ejecutar comando > python -m streamlit run app.py
